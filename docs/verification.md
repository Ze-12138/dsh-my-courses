# 验证说明

三套静态门禁，全部离线、不联网、不写文件，跑完即知结果。改代码后先跑它们，再进 GUI 看效果。

```bash
node check-client.mjs      # CLIENT OK
node check-logic.mjs       # 280 项断言 → LOGIC OK
node check-host.mjs        # 175 项断言 → HOST OK
```

## 1. 三套门禁各自守什么

### `check-client.mjs` — 浏览器入口能不能被加载

在 `node` 里伪造 `window.__ModuleLoader__` 与 `react`，把 `client.js` 当真实 bundle 加载一遍，断言：

- 只调一次 `__ModuleLoader__.load`，且 `id` 为 `@local/my-courses`
- 注册出 `sidebar.panellist:my-courses` 与 `main:my-courses` 两个槽位
- 导出 `PanelIcon`（svg）与 `Page` 组件

它挡的是「语法级错误 / 模块导出缺失」—— 这类问题在 GUI 里表现为整个面板空白，很难从界面上看出原因。

### `check-logic.mjs` — 纯函数与文案

把 `client.js` 里可以脱离 React 的部分抽出来跑真实用例，**280 项**，覆盖：

- 存储迁移：`version: 11` 的读写、旧版本补字段、坏数据兜底
- 时间与状态：`taskState` / `taskCountdown` / 逾期与已完成口径、日期格式化
- 论文：`paperVenueMeta` 的预印本降级条件、标签聚合、CCF 等级映射、质量门槛（摘要长度/标题）
- 规划：`normalizePlan` 的排序与截断、里程碑与时间线文案互斥
- 双语对照：`parseAlignedTranslation` 的严格解析（序号必须 1..n 连续、唯一、非空）
- i18n：中英文案字典键值成对、无空串

### `check-host.mjs` — 宿主路由与模型参数

把 `index.js` 读成文本做结构断言，并在沙箱里跑路由处理函数，**175 项**，覆盖：

- 9 条路由都在，路径与前缀一致（`/my-courses/…`）
- 模型调用参数被钉死：导读 `maxTokens=700 / temperature=0.3`、追问 `900`、整节对照 `1500`；`EXPLAIN_TIMEOUT_MS=90000`
- 质量门槛：摘要 <120 字符的论文不出现；`arXiv preprints` 与正式发表的 venue 区分
- 安全：SSRF 白名单（只有查表内的 arXiv 主机能进 `fetch`）、非法 `id` 返回 4xx、上游失败一律 HTTP 200 + `{ok:false}`
- SSE：`event: error` 必须带 `partial`，前端才不会卡在加载态

## 2. 渲染层验证（一次性，未随仓库发布）

`client.js` 里 JSX 较多，静态跑不了。验收时用了一个渲染探针：伪造 React 与小 hook 运行时，把页面树渲染成节点，对结构做 **99 条断言**（三个页签、便利贴分组、论文卡片标签栏、工作台三视图、段落工具组、术语表、通知样式等），结果 `99 ok / RENDER OK`。

它依赖具体类名，属于「改样式就会过期」的临时工具，因此没有进仓库。要复跑需要重新生成，别指望它长期免维护。

## 4. 明确**没有**验证的

- **加密 PDF**：本地没有稳定复现的样本，`PDF_ENCRYPTED` 分支未实测。
- **超过 200 页的 PDF**：截断逻辑只有代码路径，没有真实长文档跑过。
- **arXiv 修订后的对照缓存**：缓存不与 `updated` 绑定，版本变化后的行为未测。
- **深色模式对比度**：只做了肉眼扫视，没有量化对比度检查。
- **移动端/触屏**：只验证了窗口宽度回落，没在真机或触摸设备上试。
- **断网半途**：模型流式中途断网、SSE 中途断开的表现未系统验证。

## 5. 复跑建议

改了 `client.js` → 先 `node check-client.mjs && node check-logic.mjs`，刷新页面看效果。
改了 `index.js` → 加跑 `node check-host.mjs`，重启桌面应用后才生效（路由不会热更）。

门禁脚本本身也是代码，改断言时要问一句：**是在修探针，还是在放低标准**。改断言去迁就实现，比没有门禁更危险。
