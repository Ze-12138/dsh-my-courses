# 已知限制与后续方向

按「现在就这样、不是 bug」和「以后可能做」分开列，方便判断哪些问题不用再报。

## 一、设计取舍（不是 bug，不会改）

- **推送不联网兜底**：arXiv 拉不到时返回 `{ok:false,error}`，界面显示失败原因，不生成假数据、不缓存空结果。宁可空一天，也不放低质量条目进来。
- **「未分组」不挂学习规划**：`folderId: ''` 是虚拟桶，规划只属于真实文件夹；给虚拟桶加规划会在删除/移动文件夹时产生悬空引用。
- **论文全文字符串只进宿主内存**：`Map` 存原文，重启即失，避免把整篇 PDF 文本塞进 localStorage（几 MB 会撑爆配额）。
- **`TODO` 当天已过时刻算「已逾期 1 天」**：`taskState` 按时间点比较，没按日历日。规格未定义这一格，改口径会影响既有 24 小时内的所有任务，暂不动。
- **`normalizePlan` 先排序再截断**：超过 200 条时保留排序后的前 200 条，乱序数据下保留哪 200 条不确定。属于容量边界，不影响正常使用。
- **文件夹展开态、论文标签选中态不持久化**：都放组件内 state，切 tab / 刷新即回到默认。存进 `state.ui` 会让存储层多两处需要迁移的字段，暂时不值。
- **CCF 目录是离线快照**：等级表写死在客户端，不联网更新。新会议/改名/降级需要手工补表。
- **单文件与语言限制**：只支持文本层 PDF（`pdfjs` 抽文字），不支持扫描件 OCR；界面中英双语，但只有中文有完整文案。

## 二、能力边界（现实限制）

- **扫描版 PDF 读不出字**：`paper/pdf` 抽不到文本时返回 `PDF_NO_TEXT`，工作台明确提示「这份 PDF 没有文本层」，不会假装解析成功。
- **加密 PDF 未做专门处理**：`PDF_ENCRYPTED` 分支写了，但本地没有能稳定复现的加密样本，行为未经实测验证。
- **超大 PDF 只取前 200 页**：超出部分静默截断（只在 `paper/pdf` 的 `pages` 字段体现），不做分片续读。
- **论文缓存 7 天**：过期后 `paper/status` 不再返回该篇，需要重新抓；`PDF_NOT_CACHED` 就是过期提示。
- **逐段对照不做二次校验**：模型输出的 `[n]` 序号必须连续、唯一、非空，否则整节判为「本节未能逐段对齐」并退回原文，不会把截断的半段装成对译。
- **术语表只进提示词**：保存的术语不参与后处理替换（门禁明确禁止改写译文），只用来约束模型措辞。
- **引用是「第几段」不是页码**：`¶n` 指段落序号，与 PDF 页码无对应关系。
- **图表/公式/双栏排版**：文本层抽出来后顺序会乱，图表只剩图注，公式基本丢失。要正确还原需要版面分析（canvas/OCR），不是当前范围。

## 三、后续方向（按收益排序）

1. **版面分析**：接 `layout` 模型或 `pdfjs` 的 canvas 渲染，把双栏、图表、公式拆成结构块；顺带解决扫描件。
2. **对照结果与 arXiv 版本绑定**：缓存 key 里带上 `updated` 时间，arXiv 修订后自动失效，避免拿旧对译读新论文。
3. **全文对照的分段成本**：现在整节一次性送模型，长节会超 token；改成按段并发 + 合并，并给用户一个「只翻前 N 节」的开关。
4. **`¶n` 引用回点**：点引用 chip 滚动到对应段落并高亮（现在只显示来源，不跳转）。
5. **术语表双向**：英→中之外，增加中→英反向查询；术语命中段落时在原文里标出。
6. **推送去重与偏好学习**：现在按 `seenIds` 去重 + 方向白名单筛选；下一步按「下载/标注/提问」行为调整权重。
7. **竞赛与规划双向跳转**：`plan.linkedCompetition` 已定义未渲染，补上「这份规划对应哪场比赛」和反向入口。
8. **存储迁移框架**：`version: 11` 每次加字段都是手写迁移，抽成「版本 → 迁移函数」表，降低回滚风险。
9. **CCF 表可更新**：改成从仓库内 JSON 读取，发版即更新，不必改代码。
10. **导出格式**：现在 Markdown（含对照、术语、问答记录）；可加 PDF/DOCX，但需要处理中文字体嵌入，成本不低。
